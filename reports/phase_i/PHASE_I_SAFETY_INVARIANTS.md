## Safety-invariant test-attempt matrix (per this round's explicit request)

| Attempted action | Result | Enforcement layer |
|---|---|---|
| Call LLM while PAUSED | BLOCK | `operational_state.check_gate()` in `_call_llm` |
| Call LLM while STOPPED | BLOCK | same |
| Call a paid model | BLOCK | `evaluate_model_for_role()` via `_resolve_model_catalog()`, unconditional |
| Call a model with unknown/ambiguous pricing | BLOCK | same (`free_model_evidence()` fails closed on missing/non-numeric pricing) |
| Trigger fallback after a 429 | BLOCK (no fallback exists on the canonical path) | `_call_llm` calls `provider.complete()` directly, never `router.complete()` |
| Mutate a COMPLETED experiment's fields | BLOCK (unless `allow_amendment=True` + reason) | `research/db.py::update_fields()`/`set_research_verdict()` |
| Queue an experiment without approval | BLOCK | Phase F: 7 approval flags default `False`; `UNAPPROVED_*` validator errors; `queue_experiment_from_spec()` also now gated by operational state |
| Create a branch with a dirty tree | BLOCK, reports dirty paths | `git_isolation.require_clean_tree()` |
| Train without `new_training_approved` | BLOCK | Phase F flag hard-coded `False`; no training code path exists at all yet |
| Train without a GPU/runtime budget | BLOCK | `execution_budget.require_execution_budget()` (infrastructure only — no training code calls it yet, by design) |
| Modify a production path (`ios/`, `benchmark/config.py`) without approval | BLOCK | No code path in `research/`/`benchmark/` writes there; `production_swift_modification_approved` hard-coded `False` |
| Exceed the daily LLM budget | BLOCK | `UsageTracker.check_budget()` |
| Supply malformed/adversarial structured output | BLOCK (rejected, not coerced) | `structured_output.py`'s parse_and_validate_* functions |
| Accept a mismatched returned model | BLOCK | `ModelProvenanceMismatchError` in `_call_llm`'s success branch |

- Phase F's 7 human-authority approval flags: unchanged, still hard-coded `False` at every construction site. No new approval was granted by building this safety infrastructure.
- Queue authorization: still entirely separate from and unaffected by the operational-state gate — a `RUNNING` state does not itself authorize a queue; Phase F's validator gate is unchanged.
- Historical DRYRUN-0007 evidence: unchanged (see `reports/phase_h/DRYRUN-0007_SCHEMA_COMPATIBILITY.md` for the prior round's compatibility report; nothing in this round touched those files at all).
- No EXP-0006 was created. No experiment branch was created. No training occurred. No live OpenRouter completion request was made.
